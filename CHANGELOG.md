# Codex Hybrid Control 7.3.3

Панель подключения собственного API к настоящему Codex на Windows.

- Профили провайдеров и моделей, предпросмотр изменений и откат.
- API-агенты, управление Windows и браузером.
- Диагностика API, контроль ожидания, повторов и преждевременной остановки.
- Проверка и восстановление компонентов одной кнопкой.
- Обратимое переключение на обычный Codex.
- Восстановление сохраняет обновлённый служебный путь Codex. Отключённые компоненты отображаются корректно.

Проверено: 202 теста и запуск готового EXE. [Установка](docs/INSTALL.md).
