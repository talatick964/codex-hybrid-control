# Участие и обратная связь

Для ошибки используйте шаблон GitHub Issue. Опишите версию, последовательность действий, ожидаемый и фактический результат. Если прикладываете отчёт, сначала просмотрите его и удалите личные данные.

Не отправляйте API-ключи, `auth.json`, `.env`, личные настройки Codex, архивы браузерного профиля или необработанные логи. Для демонстрации используйте тестовое окно или отдельную временную конфигурацию.

Идеи и новости: [АИслоп в Telegram](https://t.me/aislopprogs).

Лицензия собственного кода проекта пока не выбрана. До её выбора основной путь участия — сообщения об ошибках и предложения. Лицензии сторонних компонентов перечислены отдельно.
