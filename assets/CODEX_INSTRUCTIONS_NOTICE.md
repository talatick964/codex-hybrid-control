# Источник инструкций

`codex-base-instructions.txt` получен из bundled-каталога установленного Codex CLI 0.160.0, запись `gpt-5.6-sol`, поле `base_instructions`.

Он служит резервными инструкциями для дескрипторов API-моделей. Инструкции и метаданные, полученные в полном каталоге провайдера, сохраняются при нормализации.

Проект Codex: https://github.com/openai/codex. Лицензия исходного проекта: Apache-2.0.
