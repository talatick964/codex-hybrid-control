# Исправления 7.3.3

В режиме «Обычный Codex» отключённые API-агенты и мосты больше не показываются как поломка. Проверка прямо объясняет, что для возврата API нужно нажать «Восстановить Hybrid».

Codex может менять служебный путь SKY_CUA_NATIVE_PIPE_DIRECTORY в настройках node_repl. Если изменилось только это поле, возврат Hybrid теперь сохраняет актуальный путь и восстанавливает интеграции. Любые другие изменения файла по-прежнему блокируют автоматический возврат, чтобы не потерять пользовательские настройки.

Для обновления закройте старую панель и запустите dist/7.3.3/Codex-Hybrid-Control.exe. Если включён «Обычный Codex», нажмите «Восстановить Hybrid», затем «Проверить и исправить всё». После этого перезапустите Codex.
