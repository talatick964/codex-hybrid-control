# Проверка Codex Hybrid Control 7.3.2

11 октября 2026 года, Windows.

- Полный набор: **199 тестов прошли**, без пропусков и ошибок, за 73,79 секунды.
- Настоящий Codex CLI с локальным тестовым провайдером: восстановление после обрывов, продолжение при новых результатах и прекращение повторов без прогресса.
- Дополнительные сценарии: заполненный канал MCP, повреждённый протокол, отказ записи диагностики, отказ запуска шлюза, сохранение запущенного приложения при восстановлении транспорта.
- Настройки: одновременное применение и сброс, повторная проверка режима, отказ записи снимка и компенсация частичного отката.
- API: повреждённые настройки и их восстановление, отмена без штрафа провайдеру, медленная отправка тела, разделители SSE в отдельных байтах, keepalive, обрывы и ограничения повторов.
- Проверка завершения: длинная история со старой командой остановки, вопросы с повреждёнными тегами, планы и новые результаты инструментов.
- Готовые EXE: запуск GUI, настоящее перетаскивание шапки, открытие управления компьютером и принятие каталога установленным Codex CLI.
- Готовые MCP-мосты: 4 инструмента агентов и 20 инструментов компьютера. Оба встроенных транспорта подтвердили собственный процесс и завершились при закрытии проверенного дескриптора.
- Windows UIA: заполнение настоящего поля и проверка результата. Повтор действия использовал сохранённую запись.
- Edge: отдельная тестовая сессия, переход, заполнение, клик и чтение результата.
- Готовый Worker Bridge: ограничение времени процесса; API-шлюз: запуск и ответ локального провайдера с изолированными настройками.
- Нагрузка GUI: 30 открытий и закрытий дополнительных окон, 36 переключений разделов; ошибок обработчиков нет, фоновая проверка не блокировала интерфейс.

Разбор 10 000 событий потока ускорен примерно с 4,2 до 0,4 секунды в локальном измерении. Сравнение относится к обработчику потока, а не к скорости внешнего API. Перерисовка интерфейса повторно использует неизменные изображения; проверка состояния мостов ограничена последними 16 записями.

Модельные запросы в этих проверках отправлялись локальному тестовому провайдеру. Многочасовую работу внешнего сервиса этот прогон не имитирует. Проверки не доказывают смысловую завершённость любого поручения. Изменения и порядок включения — в [FIX-7.3.2.md](../FIX-7.3.2.md).

Текущий пользовательский режим обычного Codex сохранён. Проверки использовали временные каталоги настроек.

```powershell

python verify_api_guard_release.py --dist dist/7.3.2

```
