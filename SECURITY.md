# Сообщения о безопасности

Не публикуйте действующие ключи и чувствительные данные в GitHub Issues. Если обнаружена утечка ключа, сначала отзовите его у API-провайдера.

Для приватного сообщения используйте личные сообщения каналу [АИслоп](https://t.me/aislopprogs), если они доступны. Если доступного приватного способа нет, опишите в Issue только общую проблему и попросите способ связи; сам секрет не отправляйте.

Перед отправкой отчёта просмотрите его даже после автоматического скрытия ключей. Автоматический фильтр не может распознать любую произвольную личную информацию.
